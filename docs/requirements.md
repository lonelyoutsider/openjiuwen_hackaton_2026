# Подтверждённые условия и вопросы

Обновлено 8 ноября 2026. Источники: приложенный регламент, task-dir.zip,
памятка NeuralDeep, сообщения организаторов после открытия.

## Цель и данные

- 100 задач одновременно; reward известен, назначен случайно, не отражает сложность.
- Максимизировать сумму reward правильных решений; при равенстве меньше токенов лучше.
- Общий бюджет включает оценку расхода, планирование и решение.
- Цена = output_tokens + input_tokens/10. Reasoning — выход; кеш не даёт скидки.
- Ориентир BUDGET=100000; остаток от прокси не передаётся.
- Типы: math, search, data_analysis, coding. expected в финале отсутствует.
- 8 примеров выполнимы; в финале ориентировочно 15–25% невыполнимых.
- Пропуск и неверное решение дают 0. Невыполнимость — нехватка данных для точного ответа.
- Готового train нет. Вариации задач и траектории собирает команда.

## Средства

- openJiuwen обязателен; регламент разрешает любую собирающуюся версию.
- Детерминированное решение всех задач разрешено.
- Четыре модели: qwen3.8-27b, qwen3.8-27b-noreason,
  qwen3.6-35b-a3b, qwen3.6-35b-a3b-noreason.
- Регламент разрешает переключение на каждом вызове; ранний ответ о выборе одной
  модели расходится с ним. Пока проектируем под регламент, уточняем на Q&A.
- Локальные нейросети запрещены; регрессия/бустинг разрешены.
- Runtime-сеть только к прокси. Скачивания зависимостей/данных при запуске запрещены.
- Памятка: до 60 запросов/минуту, до 16 потоков на аккаунт, до двух одновременных
  внешних IP. В финальном харнессе действует более строгий лимит до 5 сессий.
- Invite-код активируется в кабинете; API-ключ копируется отдельно оттуда.
  Код из письма не следует использовать как Bearer API key.

## Контракт запуска и сдачи

- python /app/run_agent.py --tasks-dir /data/tasks
- LLM_BASE_URL, LLM_API_KEY передают проверяющие; по чату также BUDGET.
- Ответ: task_dir/answer.txt сразу после каждого решения. При пропуске файла нет.
- Исходники и данные в task_dir/workspace/. Для coding исправлять исходники,
  не тесты; в answer.txt писать DONE. Финальную проверку workspace уточнить.
- Runtime 1 час, RAM 16 ГБ, без GPU, до 5 одновременных сессий.
- CPU: таблица 4 ядра, команда Docker 8. Пока ориентируемся на 4.
- Read-only root, HOME=/tmp, /tmp writable 2 ГБ, каталог задач writable.
- Сборка до 1000 секунд; образ <4 ГБ; repo без .git <100 МБ.
- Фиксированные версии зависимостей и базового образа.
- Приватный GitHub допустим: до дедлайна жюри promsoft и madrugado должны получить доступ.
- Оценивается последний коммит на момент закрытия; поздние коммиты игнорируются.
- Проверки: безопасность → сборка → обе задачи минимального отбора → полный набор.
  Провал первых трёх этапов означает незачёт.
- MCP-квалификация закрыта 7 ноября 00:00 по сообщению организаторов, не выполняем её.
- Онлайн-этап 7–13 ноября, Q&A 9 ноября 15:30 МСК, награждение 20 ноября.
  Точный час сдачи не установлен.
