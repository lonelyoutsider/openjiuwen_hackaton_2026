## Цель и контракт

100 задач, reward известен. Максимум reward при общем бюджете
output + input/10; при равных баллах меньше токенов лучше. Не отдельный MAE.
Настоящий openJiuwen обязателен, закреплён 0.1.19. Docker/Python 3.12;
системный Python 3.14 пользователя не является конкурсным окружением.
Runtime-сеть только к предоставленному прокси; без GPU и скачиваний.
Ключ передаётся через env локально, не через чат, git или аргументы команды.

## Что работает

- Детерминированный первый проход, затем ограниченный JSON/tool агент
  через реальный WorkflowComponent/Runner.
- Общий ledger с резервом перед API-вызовом; usage prompt/10 + completion,
  reasoning повторно не добавлять. При неопределённом расходе повторов нет.
- Приватная копия workspace, неизменяемые тесты, unittest перед публикацией.
- Docker baseline и первый реальный Qwen-прогон подтверждены пользователем.
- Есть ограниченная opt-in диагностика и выбор поднабора --only.

## Режим работы

Пользователь поручил ассистенту писать код и фиксировать изменения в GitHub;
он и Миша анализируют идеи и результаты. Ветки/PR обязательны. Не перезаписывать
работу другого участника. Не запускать две серии с командным ключом параллельно.
В этом чате нет прямого доступа к Windows-ноутбуку: локальный Codex запускает
подготовленный код в Docker, возвращает отчёт; результаты записываются в progress.md.

Перед изменением: git status, fetch, изучение выбранной ветки.
Проверки: python -m unittest discover -s tests -v;
python scripts/evaluate_examples.py в окружении requirements.lock.
Mock-usage не считать измерением Qwen. Пропуск SDK-теста явно сообщать.

Не использовать expected/ID как признаки. Не менять официальные примеры.
Не путать unsupported, call limit, tool error и insufficient_data.
API base при разработке: https://api.neuraldeep.ru/v1, на оценке — env проверяющих.
Квалификация закрыта; регистрацию/heartbeat не выполнять.
Автоматической синхронизации истории между чатом и IDE нет: контекст хранится
в коммитах и документах. Обновлять этот файл при изменении следующего шага.
