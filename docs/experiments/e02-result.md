## Выбор кандидата

Edit и recovery включены в стандартный CLI. JSON автоматически включается
только для HTTPS api.neuraldeep.ru с обычным портом443; на неизвестном адресе
прокси используется обычный запрос с recovery. Предоставленный URL не меняется.
Принудительные --json-mode/--no-json-mode доступны для диагностики.
Никакого повтора при отказе неизвестного прокси: списание может быть неизвестно.

Отдельное изменение резерва обусловлено новым официальным уточнением:
BUDGET может быть меньше или больше100k. Запрошенный output cap1024 теперь
снижается до значения, помещающегося в остаток после прежнего консервативного
резерва input. Минимум64, если запрошено не меньше64. Если и это не помещается,
HTTP не отправляется. Это исправление потенциального budget_stop, не измеренный
выигрыш качества. Следующий один прогон проверяет именно release defaults.
