## Причины

- Intervals: оба ответа содержали корректное полное исправление после пояснения.
  Strict отверг JSON и перед вторым запросом остановился: резерв1551.6,
  остаток1404.2. Recover принял действие в первом ответе; видимые и независимые
  проверки прошли, получены2 балла. Здесь подтверждён ожидаемый механизм.
- Ledger: оба варианта решили задачу за2 вызова. В recover первый ответ
  содержал корректный JSON в fenced-блоке с меткой python, который разборщик
  отверг, признавая в этом месте только json/пустую метку. Второй ответ принят.
- Tags: оба варианта достигли лимита4 вызовов. Файлы уже были в initial_context,
  но модель тратила шаги на повторное чтение и сообщения без JSON. Затем она
  вызвала несуществующий unicodedata.casefold; тесты отклонили исправление.
  Это ошибка сгенерированного кода/распределения шагов, а не нехватка данных.
  Неуспешные исходники не опубликованы в оригинальном workspace.
- Во всех14 фактических API-вызовах finish_reason=stop и reasoning_tokens=0.
  В этой паре нет подтверждённой остановки генерации по выходному cap.
  Повествовательный ответ может закончиться сам без команды; увеличивать
  output cap как лечение такого случая оснований пока нет.

Набор coding-edit-v1 уже используется для разработки; он не является holdout.
Основной CLI допускает6 вызовов по умолчанию, но эти эксперименты ограничены4.
По этому результату нельзя объявить tags принципиально нерешаемым для модели.

## Исправление и следующий шаг

Исправлена обработка полного JSON после пояснения внутри fenced-блока:
метка языка не важна, содержимое всё равно разбирается только JSONDecoder.
Лишний код до/после объекта, обрыв и несколько объектов остаются запрещены.
Записанный первый ledger-edit воспроизведён бесплатно на исходном кейсе:
видимые и независимые проверки проходят. Это offline-проверка действия,
не новый live-результат и не измеренная экономия вызовов.

Далее — небольшой probe response_format=json_object по документации NeuralDeep,
затем при совместимости — сравнение на смешанном validation-v1, чтобы не
продолжать подгонять только три coding-задачи. Протокол: [json-mode.md](json-mode.md).
Флаги edit/recovery/JSON по умолчанию пока отключены. Сырые отчёты не коммитятся.
