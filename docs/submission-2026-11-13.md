## Сдаваемый запуск

```bash
docker build -t its-ia:final .
python /app/run_agent.py --tasks-dir /data/tasks
```

Вторая команда исполняется внутри образа проверяющими. LLM_BASE_URL,
LLM_API_KEY и BUDGET задаются в окружении. Ключи в git отсутствуют.

- Python3.12.14,openJiuwen0.1.19,закреплённый base image/requirements.lock.
- Qwen3.8-27b-noreason,6 вызовов/задачу,output cap1024 с адаптацией к бюджету.
- Сначала детерминированная фаза, затем LLM/tool workflow.
- Edit/recovery/compact ON; JSON auto только проверенный HTTPS NeuralDeep.
  Неизвестный proxy получает обычный chat и recovery. URL не заменяется.
- BUDGET из env любой положительный, собственный ledger output+input/10.
  Reasoning не прибавляется повторно; unknown usage останавливает расход.
- Компактные preview явно маркируются; полные данные доступны Python-tools.
- SDK Session timeout связан с оставшимся общим deadline; свой лимит3300с.
- answer.txt рядом с task.json, отсутствует при пропуске; coding:DONE и
  исправленные исходники после unittest, тесты защищены от изменения.
- Read-only /app, HOME=/tmp, writable/tmp и task dirs,без GPU/runtime downloads,
  сеть только предоставленный proxy. Dockerfile/lock в финализации не менялись.
